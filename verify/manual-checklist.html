Pre-install checklist

Use this public checklist before running any npx skills add command from the Verified Shelf. It does not replace scanners (SkillSpector / AcidTest); it is the v1 gate when those URLs are not attached.

← Back to shelf

  1. Confirm the card’s pinned_ref matches the commit or tag you will install (@sha in the command).
  2. Fetch the skill entry file at that ref from the public repo and compute sha256sum.
  3. Compare your digest to the card’s content_sha256. Do not install on mismatch.
  4. Skim SKILL.md for unexpected network calls, credential exfil, or post-install rewrite hooks.
  5. Prefer a project-scoped install first; review agent tool permissions after reload.
  6. Record the pin + hash you verified (PR comment or notes) so a later silent file change is visible.
